# Хорнет

Лёгкий «стеклянный» корпус игрока. Простой прямоугольник со срезанным носом.
Медленнее, но поворотливее и чуть крупнее Васпа — это машина обороняющегося снайпера.

## В игре (`CONFIG.hulls.hornet`)

| Параметр | Значение | Смысл |
|---|---|---|
| `speed` | 112 | скорость, px/с |
| `turn` | 1.6 рад/с | поворот корпуса (быстрее Васпа, но медленнее башни 2.1) |
| `radius` | 17 | хитбокс (круг), чуть меньше корпуса |
| `len` × `wid` | 50 × 26 | габариты силуэта |
| `shape` | `boxy` | прямоугольник со срезанным носом |
| `turretBack` | 0 | башня по центру корпуса |
| `barrel` | 46 | длина ствола (одинакова с Васпом — оружие одного класса) |
| `color` | `#3d6e8c` | стальной |

## Заметки по балансу

Габариты держат намеренно одинаковую ширину с Васпом: широкий танк — просто
более крупная мишень, то есть скрытый дисбаланс. Разница между корпусами
должна быть в характере (силуэт, смещение башни), а не в размере мишени.
Хитбокс круглый и меньше корпуса: попадание по краешку брони ощущается нечестно.

См. [railgun](../turrets/railgun/railgun.md), [wasp](wasp.md).
