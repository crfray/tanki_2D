# Из чего собраны карты

Карта — **список предметов**. Один и тот же список собирает бой
(`buildMap`) и рисует картинку (`drawProps`), поэтому расходиться им
нечему: что описано, то и едет.

Новые карты собираются здесь, в `MAPS`: списком это быстрее, чем мышью.
А встроенный **редактор** оставлен для другого — **править готовые карты
и сохранять их файлом**.

## Предмет

```js
{ type: 'wall', x: 0.30, y: 0.42, w: 0.14, h: 0.022 }
```

Коробка в **долях арены** — ширина арены зависит от окна, пиксели
разъехались бы на первом же экране. Круг (дерево, столб, водобашня)
вписывается в свою коробку: одно правило вместо двух.

Особые поля: `side` (`player` / `bot`) у базы и точки появления,
`bot: true|false` и `a` (угол в радианах) у точки появления.

## Каталог (`PROPS`)

| type | что | мешает ехать |
|---|---|---|
| `ground` | пятно земли | нет |
| `puddle` | лужа | нет |
| `bridge` | мост, настил | нет |
| `bush` | кусты | нет |
| `tree` | дерево | круг |
| `wall` | бетонная стена | да |
| `fence` | забор со столбиками | да |
| `house` | дом с коньком | да |
| `hangar` | ангар с воротами | да |
| `shed` | будка | да |
| `tower` | водонапорная башня | круг |
| `watch` | наблюдательная вышка | да |
| `pipe` | трубопровод с муфтами | да |
| `post` | столб | круг |
| `pole` | опора ЛЭП с траверсой | круг |
| `wreck` | остов сгоревшего танка | да |
| `plateau` | возвышенность | особое: см. ниже |
| `ramp` | подъём на возвышенность | особое |
| `base` | база CTF | разметка |
| `spawn` | точка появления танка | разметка |

Размер задаётся у каждого предмета отдельно, поэтому «мост подлиннее»
или «стена потоньше» — это просто другие `w`/`h`, а не отдельный вид.

### Высота

`plateau` — приподнятая площадка: заехать наверх можно **только** через
`ramp`, съехать — с любого края. Площадок может быть несколько, в том
числе вложенных: остров на дворе — это вторая площадка внутри первой, и
ярус танка считается по тому, сколько площадок его накрывают.

Подъём снимает кромку только у **своей** площадки — той, в которую он
врезан.

Возвышенность — **масса, а не разметка**: она загораживает выстрелы, как
всякое препятствие. Не загораживает только та площадка, на которой стоит
кто-то из двоих: он либо стреляет с неё, либо стоит на ней мишенью.
Отсюда главное: **стоя внизу за углом возвышенности, ты укрыт**.

Если загораживать нечему, дальше решает предел ствола (`CONFIG.height`):

| Кто стреляет | Когда достанет |
|---|---|
| сверху вниз | только у самой кромки (ближе `brink` = 45 px) |
| снизу вверх | только отъехав от обрыва (дальше `standoff` = 90 px) |
| на одном ярусе | всегда |

Отъехал — достаёшь всех наверху: и того, кто у кромки, и того, кто в
середине площадки. Не отъехал — луч и снаряды бьют в откос, там же
остаётся след.

Правило одно на все пушки: луч рельсы, летящие снаряды, конусы огнемёта
и фриза, поток изиды. И бот его знает — он больше не палит в
возвышенность, за которой ты стоишь.

### Разметка

`base` задаёт базу CTF своей стороны (и дом для флага), `spawn` — точку
появления танка. Сколько точек поставлено, столько машин и выедет; у
каждой сторона, признак «бот / игрок» и, если надо, корпус:

```js
{ type: 'spawn', side: 'bot', bot: true, hull: 'wasp', a: 2.35,
  x: 0.71, y: 0.05, w: 0.055, h: 0.04 }
```

`hull` не задан — бот выезжает на Васпе, а игрок на том, что выбрал в
гараже. Состав команд, таким образом, виден прямо в карте.

- Живого игрока может не быть вовсе — тогда дерутся одни боты.
- Свои друг друга не бьют, бот целится в ближайшего живого противника.
- Счёт идёт **стороне**, а не танку.

Если карта не задала ни баз, ни точек появления, игра ставит их сама по
углам — иначе матч оказался бы без опорных точек.

## Две формы описания

- **Список предметов** (`items`) — когда важен не только бетон:
  [sandbox](sandbox.md) собран так, из него растут башня, барак и зелень.
- **Половина расстановки** (`cover` + `solo` + `base`) — когда вся соль в
  симметрии: [boombox](boombox.md) описан половиной, вторая половина
  достраивается поворотом на 180°.

Обе формы разворачиваются в один и тот же список предметов
(`presetItems`).

## Редактор

Кнопка «Редактор карт» в меню. Открывается сразу с той картой, которая
выбрана, поэтому обычный путь такой: выбрал Sandbox → редактор →
подвинул что мешает → «Сохранить в файл».

| | |
|---|---|
| Взять готовую | перебирает встроенные карты по кругу |
| ▶ Правка | взять предмет, двигать, тянуть за угол. Режим по умолчанию |
| палитра | щелчок кладёт новый предмет, в том числе поверх возвышенности |
| Esc / тот же значок | вернуться в правку |
| Shift + щелчок | взять предмет, не выходя из постановки |
| ПКМ, Delete | убрать |
| колесо | размер выбранного |
| R | повернуть точку появления танка |
| Ctrl+Z / Ctrl+Y | отменить / вернуть, до 100 шагов |
| Сохранить в файл | имя вписываешь сам, оно же имя файла |
| Открыть файл | чужой или битый файл игру не роняет |
| Играть | матч прямо по тому, что на экране |

Режим написан внизу крупно и первым словом: главная путаница любого
редактора — «жму по объекту, а создаётся новый».

Файл карты:

```json
{ "format": "tanki-map-1", "name": "Моя арена", "items": [ ... ] }
```
